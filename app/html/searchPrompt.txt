### API REFERENCE

#### 1. POST /keyPressed/autoindex/:dir/:keys
* Purpose: Fetch a list of records matching a name prefix AND/OR passing complex filters.
* :dir — The data collection name (e.g., pokedex, trainers, users).
* :keys — The string typed by the user. 
* CRITICAL JS HANDLING: If the user search input is empty, ensure the frontend handles the URL properly (e.g., passing an empty string or fallback) to prevent 404 routing errors on the server.

#### 2. POST /keyPressed/data/:dir/:name/:field
* Purpose: Fetch a specific field (or nested object) from one exact record.
* :dir — The data collection name.
* :name — The unique record ID (e.g., "abomasnow", "abomasnow_2").
* :field — The specific field to retrieve. Supports dot notation for nested fields (e.g., "Stats.HP").

### REQUEST BODY SPECIFICATIONS
Both endpoints require a POST request with a JSON body containing a "conds" array. If no filtering is applied, send an empty array: `{"conds": []}`.

Structure of a condition object:
{
  "field": "FieldName",
  "cond": "EQUAL | EQUAL_GREAT | EQUAL_SMALL | GREAT | SMALL | HAS",
  "value": "valueToCompare",
  "expect": true,
  "next": "AND | OR | "
}

CRITICAL CHAINING RULES FOR JAVASCRIPT GENERATION:
1. "expect": true means the condition must be met. false means it must NOT be met.
2. "next": Defines the chain logic. "AND" (if this fails, whole chain fails), "OR" (if this fails, jump to next OR).
3. LAST ELEMENT RULE: The very last condition object in the "conds" array MUST explicitly have `"next": ""` (an empty string). Do NOT omit the key and do NOT set it to undefined, otherwise JSON.stringify will strip it, breaking the backend parser.
4. DATA TYPE CASTING: In your generated JavaScript, before building the payload, ensure you cast the user inputs properly. Convert "true"/"false" strings to actual Booleans, and numeric inputs to actual Numbers, so the backend can perform accurate mathematical comparisons (GREAT/SMALL).
5. Nested fields use dot notation ("Height.Meters"). Array fields are searched recursively ("Moves.Name").
